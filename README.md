## How to Use These Subscription Links

1. Pick a link from the lists below (start with **Mixed Subscription Links** if you are not sure) and copy it.
2. Open your V2Ray client and go to **Subscriptions / Subscription groups / Profiles**.
3. Add a new subscription, paste the link and save.
4. Update the subscription, run a latency (ping) test and connect to the config with the lowest delay.
5. Refresh the subscription from time to time. Free configs rotate quickly, so re-importing keeps your list fresh.

## Tips for Better Speed and Stability

- **Always run a ping test** after importing a subscription and pick the lowest-latency configs.
- **Use protocol-specific lists** (VLESS, Trojan, Shadowsocks...) if your client becomes slow with very large mixed lists.
- **Try several subscriptions.** Free servers are shared, so quality differs between lists and changes during the day.
- **Prefer TLS or Reality based configs** (VLESS Reality, Trojan, VMess over TLS) when your network blocks plain protocols.
- **Update subscriptions regularly** to remove dead configs and get new ones.

## FAQ

### What is a V2Ray subscription link?

A subscription link is a URL that returns a list of proxy configurations (VLESS, VMess, Trojan, Shadowsocks and others). Instead of adding configs one by one, you add the URL once and your client downloads and refreshes the whole list.

### Which protocol should I choose?

There is no single best protocol. VLESS with Reality or TLS and Trojan are popular choices on restricted networks, Shadowsocks is lightweight, and Hysteria2/TUIC can be fast on lossy connections. Start with the mixed list, test, and keep what works on your network.

### Why does a link or config not work?

Free configs are public and shared, so servers go offline, get overloaded or get blocked. Update the subscription, run a ping test, try another config, or switch to another list. If a whole link is dead, please open an issue.

### Can I use these links on iPhone, Android, Windows, macOS and Linux?

Yes. See [Compatible Clients](#compatible-clients). Make sure your client supports the protocol of the list you import (for example Hysteria2 and TUIC need newer sing-box based clients).

### Are free V2Ray configs safe?

Treat them as untrusted. The server operators are unknown, so avoid logging in to banking, email or other sensitive accounts through free public configs, and prefer HTTPS websites.

## Contributing

Know a working subscription link, or found a dead one? Open an [issue](https://github.com/mehdirzfx/v2ray-sub/issues) or a pull request and it will be added or removed in the next update. If this list helps you, give the repo a star.

4. اشتراک را آپدیت کنید، تست پینگ بزنید و به کانفیگی با کمترین تأخیر وصل شوید.
5. کانفیگ‌های رایگان زود از کار می‌افتند، پس هر چند وقت یک‌بار اشتراک را دوباره آپدیت کنید.

### نکات

- اگر کلاینت با لیست‌های خیلی بزرگ کند شد، از لیست‌های جداگانه هر پروتکل (VLESS، Trojan، Shadowsocks) استفاده کنید.
- کانفیگ‌های رایگان عمومی هستند و سرور آن‌ها دست افراد ناشناس است. برای حساب‌های بانکی و کارهای حساس از آن‌ها استفاده نکنید.
- اگر لینکی خراب بود یا لینک سالم جدیدی دارید، از طریق [Issues](https://github.com/mehdirzfx/v2ray-sub/issues) خبر بدهید.
